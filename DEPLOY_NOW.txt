================================================================================
TROUBLESHOOTING
================================================================================

Most common issues:

Issue: "Cannot connect to API"
  → Backend still building (wait 2-3 min)
  → Check Render logs for errors
  → Verify DATABASE_URL is correct

Issue: "Database not found"
  → Verify Supabase CONNECTION_STRING in Render
  → Check Supabase project is active
  → Test connection manually with psql

Issue: "Slow to load"
  → Render free tier might be sleeping (first request = 30 sec)
  → Subsequent requests are fast
  → This is normal for free tier

See DEPLOY_FREE.md section "Troubleshooting" for more help.
